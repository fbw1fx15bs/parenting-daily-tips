# 南溪山医院率先开展常规新冠病毒核酸检测，攻略请收藏！

> 更新时间：2026-09-16 (UTC+8)

目前，我国新冠肺炎疫情得到有效控制，成为全世界最安全的国家，但随着复工复产复学的逐步推开，我国正面临着外防输入、内控反弹的双重压力。

为了满足广大企事业单位及湖北返桂复工复产人员、密切接触者以及部分群众进行检测的心理需求，作为收治新冠肺炎的定点医院，经相关政府部门及专家核验认定，自治区南溪山医院成为了桂林市首批具备新冠病毒核酸检测的定点机构，已于4月13日起开展了常规新冠病毒核酸检测，为广大有特定需求的人员在采血和肺部CT检查的专项检测基础上增添了一份贴心的服务及轻松的选择。

南溪山医院不仅为个体提供核酸检测，同时也为各机关企事业单位等团体提供团检的核酸检测服务。

小编根据大家关心的问题，

特地整理了检测攻略，请收藏！

**01**

检测的项目有哪些？什么时间可以检测？

答：开展的项目有新冠病毒核酸检测和新冠抗体检测。此外，为及时满足群众的检测需求，南溪山医院的检测时间由原来的周一三五已改为周一至周五每天均可进行检测。（咨询电话：0773-3836484）

**02**

检测需要预约吗？多久可以拿到结果？

答：新冠病毒核酸检测者可提前预约，也可当日到医院后开单检测。上午检测、下午即可获取检测结果（可手机随时查询检测结果，也可使用就诊卡刷卡领取结果），高效率的检测为临床诊断和治疗提供了宝贵的时间，为控制疫情做出了不懈的努力和贡献。此外，检测无痛、无创伤、高效率，让受检者安心、放心、更舒心。

**03**

哪些人需要进行检测？

答：需要检测的重点人群包括从事公共场所服务、交通工具服务及养老机构、监狱、看守所等特殊场所服务的人员，教师，医护人员，以及相对密闭场所工作人员。如果普通人没有呼吸道症状，没有发热，也没有流行病学史，没有必要做核酸检测，但如果有发热等呼吸道症状，或重点疫区流行病学史的人士，可以做核酸检测。

**04**

核酸检测多少钱？可以刷医保吗？

答：根据桂林市统一收费标准，新冠病毒检查均可刷医保卡进行支付，新冠病毒核酸检测费用为260元/次，新冠病毒抗体检测120元/次。

**05**

普通民众想检测该如果操作？

答：为方便广大民众检测，南溪山在发热门诊、体检门诊及呼吸科门诊均开通检测服务。普通民众通过关注南溪山医院微信公众号捆绑就诊卡，到发热门诊、体检门诊及呼吸科门诊开具核酸检测单，完成方便快捷的手机缴费或刷医保卡缴费，到发热门诊进行采样后，下午便可在手机上及时查询检测结果，如需纸质报告也可到医院自助机自主打印。

**06**

企事业单位想组团检测该如何操作？

答：南溪山医院健康体检科已开通为众多机关企事业单位的人员进行团体核酸检测的服务。通过制定详细周密的核酸检测流程，截至目前，健康体检科已完成30余人的体检核酸检测制单、预约采样、出具报告等项目，后续仍有单位预约检测，极大地满足了团体单位的检测需求。
